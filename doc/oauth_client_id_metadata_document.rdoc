The +oauth_client_id_metadata_document+ feature implements the OAuth Client ID Metadata Document spec.

https://datatracker.ietf.org/doc/draft-ietf-oauth-client-id-metadata-document/

This feature depends on the +oauth_authorize_base+ feature.

== Auth Value Methods

* oauth_applications_created_via_client_id_metadata_column :: the db column which tells whether the application was created via CIMD, <tt>nil</tt> by default.
